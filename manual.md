# Tip Calculator – User Manual

1. Launch the **TipCalculator** app.
2. Enter the **Check Amount** (a number such as `84.50`; it cannot be negative).
3. Enter the **Party Size** (a whole number, 1 or more).
4. Tap **Compute**.
5. The table shows, for 15%, 20% and 25% tips, the **tip per person** and the **total each person pays**. The check is split evenly and values are rounded to the nearest integer.

If a field is empty or invalid (e.g., negative check, party size of 0, non-numeric text), a message appears at the bottom of the screen and no results are shown. Fix the input and tap **Compute** again.
